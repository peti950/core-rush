# 코어 러시 (Core Rush)

땅을 파서 광물과 유물을 모으고, 몰려오는 적에게서 우주선을 지키는 디펜스 로그라이크.

## 휴대폰에 설치 (APK)
1. [최신 빌드](../../releases/latest) 페이지에서 `CoreRush.apk`를 눌러 내려받아요.
2. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해요.

## 웹으로 플레이
저장소 Settings → Pages에서 Branch를 `main` / `/docs`로 켜면 `https://peti950.github.io/core-rush/` 에서 바로 할 수 있어요.

## 폴더
- `docs/` 게임 본체 (index.html, title.jpg)
- `android/` 안드로이드 앱 껍데기 (전체화면 WebView, 가로 고정)
- `.github/workflows/build.yml` 푸시하면 APK를 자동으로 빌드해서 Releases에 올려요.
